# scripts/

The generator, compile, deploy, bundle and fixture scripts of the contract sets, on the
layout of `acedward/mip-0018-midnight-contracts` (project 00024-02, phase 02-B):
`compile.sh` (`compact compile +0.34.0`, one contract at a time), the literal-contract
generator, the local-chain deploy-and-publish script (network from the `MN_*`
variables), the bundle step (`public-interface-deploy-check`, patched copy in
`../tools/public-interface/`) and the fixture exporters.
